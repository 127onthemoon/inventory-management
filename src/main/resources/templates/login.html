高并发库存管理Inventory System · Java 课程结课项目

库存扣减交给数据库的一条原子语句，并发再高也不会超卖。

出库时不先查后改，而是把“库存够不够”写进 UPDATE 的条件里：受影响行数为 1 才算扣减成功，为 0 就是库存不足，直接拒绝。

-- ProductRepository.decreaseStock
UPDATE product
  SET stock = stock - :qty
WHERE id = :id AND status = 1
  AND stock >= :qty;
