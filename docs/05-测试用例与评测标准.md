# 测试用例与评测标准（评测集）

> 本文件是“可验收的规格”：每条用例都对应一个自动化测试方法或脚本步骤，执行结果见 `06-测试报告.md` 与 `07-性能测试报告.md`。

## 1. 评测标准

| 指标 | 通过标准 |
|---|---|
| 编译 | `mvn clean package` BUILD SUCCESS |
| 自动化测试 | `mvn test` 失败数 = 0，错误数 = 0 |
| 防超卖 | 任意并发下成功出库总量 ≤ 初始库存 + 入库总量；最终库存 ≥ 0 |
| 精确性 | 库存 50、100/500 并发各出库 1：成功**恰好** 50，最终库存**恰好** 0 |
| 幂等 | 同一 request_id 任意次数（含并发）提交：库存只减少一次，只有 1 张单据、1 条流水 |
| 一致性 | 库存 = Σ入库 − Σ出库（流水与单据两种口径都成立）；流水条数 = 单据数；流水链连续 |
| 回滚 | 库存不足、写单据失败等异常后：库存不变、无残留单据/流水 |
| 权限 | 未登录 302/401；操作员访问管理功能 403；管理员全部 200 |
| 页面 | 全部页面登录后 200 且无模板错误 |
| 压测 | 系统错误率（5xx/连接错误）= 0%；业务拒绝（409）单独统计；压测后 SQL 核对全部 OK |
