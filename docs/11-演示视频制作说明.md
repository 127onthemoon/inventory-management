## 4. 制作流程

```
narration.json ──► scripts/tts.py ──► public/audio/*.mp3（逐句配音）
      ▲                 │            src/timeline.json（每句起止时间）+ out/demo.srt
      │                 ▼
src/data.json ◄── scripts/build-data.mjs（解析真实结果文件）
                        │
scripts/record.mjs ◄────┘ 按 timeline 中每句旁白的时间点驱动浏览器操作
  Playwright + 系统 Chrome，视口 1440×810 × 缩放 4/3 = 1920×1080
  CDP Page.startScreencast 抓取 JPEG 帧（带真实时间戳）→ ffmpeg concat → public/clips/<场景>.mp4（30fps, CRF 16）
                        │
Remotion（src/Demo.tsx 等）：片头/数据动画/总结 + 录屏片段 + 章节标签 + 烧录字幕 + 逐句音频
  → build/remotion-render.mp4（H.264 CRF 18 + AAC 192k）
                        │
ffmpeg：视频流直接复制，音频 loudnorm 响度标准化，+faststart → out/demo.mp4
```

说明：
- **字幕与朗读分离**：`narration.json` 中的一句可以写成 `{"text": 字幕原文, "say": 朗读文本}`。字幕保留原文，朗读改成自然中文读法，例如字幕“P95 响应时间 456 毫秒”→ 朗读“百分之九十五的请求在 456 毫秒内完成”；“JMeter”→“J-Meter”；“SVG”→“矢量图”；“403”→“四零三”；“JPA、MySQL”→“J P A、My S Q L”。
- **旁白、字幕、画面同一时间轴**：每条字幕单独合成一段语音并用 ffprobe 量出真实时长，字幕的起止时间就是这段语音的起止时间；录屏脚本里的点击、输入也按这些时间点执行，所以讲到“确认框”时画面正好弹出确认框。
- 无头浏览器不绘制鼠标，录屏时注入了一个跟随真实 `mousemove` 事件的箭头和点击波纹，便于观看。
- 没有使用 Playwright 自带的 `recordVideo`：它固定低码率 VP8，界面文字发糊；改用 CDP 截屏流（JPEG 质量 92）保证文字清晰，本质上同样是对真实页面的连续录制。

## 5. 重新制作

前提：应用在 8080 运行（`scripts/start.sh`），本机有 Chrome（`/usr/bin/google-chrome`）、ffmpeg、Python 3 + `pip install edge-tts`（需联网调用微软 TTS）。

```bash
cd demo-video
npm install                 # remotion 4、playwright、字体与图标包
npx remotion browser ensure # 下载 Remotion 渲染用的 headless shell
npm run all                 # data → tts → record → render → mux，输出 out/demo.mp4 与 out/demo.srt
# 单独调整：npm run studio 打开 Remotion Studio 预览；node scripts/record.mjs outbound 只重录某一场景
```

渲染耗时参考：本机 8 vCPU，Remotion 并发 4，约 3.5 分钟。

## 6. 检查记录

- `ffprobe`：时长 180.5 s、1920×1080、30 fps、h264 + aac（48 kHz 立体声）（见第 1 节）。
- `volumedetect`：平均 −19.5 dB，峰值 −1.5 dB，无削波。
- 抽取 11 帧查看（`demo-video/out/frames/`）：中文字幕显示正常、无乱码；字幕与画面一致，例如 036s 字幕讲指标条，画面为 20 个商品 / 库存 1,323 / 低库存 5；075s 讲入库预览，画面为 7 → 37；160s 字幕“JMeter … P95 响应时间 456 毫秒”，画面为 632.83 req/s、456 ms。
- 局限：没有人工“试听”环节，旁白质量依赖 edge-tts；英文缩写已改写朗读文本，但“Spring Boot”“Thymeleaf”“Java”等仍按 TTS 默认英文读法。
