# 10 前端重构说明

> 时间：2026-11-16　　范围：全部 Thymeleaf 页面、`static/css/app.css`、`static/js/app.js`
> 约束（沿用原方案）：Thymeleaf + 原生 HTML/CSS/JS，不引入 Vue/React/构建工具；字体与图标全部本地放置，不依赖外网 CDN；**后端接口、权限与业务逻辑不做任何修改**。

## 2. 设计方案

### 2.1 方向：「仓储台账」

主题是仓库库存，所以视觉语汇取自仓库现场：钢梁灰的侧栏、混凝土浅灰的地坪底色、托盘标签青作为主操作色，**唯一的大胆元素**是地面安全标线的“安全黄 + 黄黑斜纹警示带”——只出现在三处：当前导航定位条、低库存水位条、登录页底边。

| 令牌 | 值 | 用途 |
|---|---|---|
| `--steel-900` | `#17232a` | 侧栏、登录页主视觉 |
| `--concrete` | `#eef1f0` | 页面底色 |
| `--paper` | `#ffffff` | 卡片、表格 |
| `--teal` | `#1d5c63` | 主按钮、链接、焦点环 |
| `--signal` | `#f2b200` | 当前位置、低库存警示（唯一强调色） |
| 语义色 | 入库 `#23704a` / 出库 `#b44a12` / 危险 `#b42318` | 入库/出库/错误，均满足白底 4.5:1 |

字体：IBM Plex Sans / Plex Mono（拉丁字母与数字，本地 woff2 共约 120 KB，OFL 协议），中文走系统黑体栈（PingFang SC / 微软雅黑 / Noto Sans CJK SC）。
图标：Lucide（ISC 协议）34 个图标打包为本地 SVG sprite `static/css/icons.svg`（约 10 KB），模板通过 `fragments/icons.html` 片段引用。

> 静态文件都放在 `/css/**` 下，复用 `SecurityConfig` 已有的放行规则，因此**没有改动任何 Java 代码**。

### 2.2 布局

```
┌──────────┬──────────────────────────────────────────────┐
│ ▣ 品牌    │ ☰  基础资料 / 商品管理            (系) 姓名 · 角色 [退出] │ ← 顶栏：面包屑 + 用户
│ 概览      ├──────────────────────────────────────────────┤
│ ▌数据统计 │ 页面标题 + 说明                          [主操作] │
│ 基础资料  │ ┌指标条（一块面板 4 分区）────────────────────┐ │
│  商品…    │ └────────────────────────────────────────────┘ │
│ 库存作业  │ ┌趋势图 (SVG) ─────────┐ ┌库存健康度 + 低库存┐ │
│  入库…    │ └──────────────────────┘ └──────────────────┘ │
│ 系统      │ ┌表格（水位条 / 徽标 / 行操作 / 空状态 / 分页）┐ │
│ ● MySQL   │ └────────────────────────────────────────────┘ │
└──────────┴──────────────────────────────────────────────┘
≤1024px：侧栏变抽屉（☰ 打开，遮罩/Esc 关闭）；≤640px：单列表单、指标两列
```

### 2.3 与“通用模板”的刻意区别（按 frontend-design 的自查要求）

- 指标用**一块面板分 4 区**，而不是 4 张一模一样的卡片；低库存数大于 0 时数字变红。
- 去掉所有 emoji 图标（原侧栏、按钮都用 emoji），统一为 Lucide 线性图标。
- 去掉按钮/链接末尾的 `→`、`←` 字符，改为图标；不使用全大写英文小标签。
- 登录页主视觉不是口号，而是系统**真正用来防超卖的那条 SQL**（`ProductRepository.decreaseStock`）和两项真实测试结果。

## 3. 重构内容（逐页）

| 页面 | 模板 | 主要变化 |
|---|---|---|
| 公共布局 | `fragments/layout.html` | 新侧栏（图标+文字、分组、黄色定位条、`aria-current`）、顶栏面包屑（JS 根据当前导航生成）、用户角色说明、小屏抽屉；成功消息改为右下角 Toast，警告/错误为常驻提示；全局 `<dialog>` 确认弹窗；跳到主内容链接 |
| 图标片段 | `fragments/icons.html`（新增） | `ic(name)` / `ics(name)` 两个片段，引用本地 sprite |
| 登录 | `login.html` | 左右分栏：左侧 SQL 主视觉 + 真实测试数字 + 警示带；右侧登录表单与演示账号 |
| 数据统计 | `dashboard.html` | 指标条；**原生 SVG 柱状图**（数据取自页面内可访问表格，支持线性/对数刻度切换和悬停提示）；**库存健康度环形图**；低库存列表带水位条与补货按钮；最近流水用 +/− 与“前 → 后”展示 |
| 商品列表 | `products/list.html` | 搜索框带图标；名称+编码合并为一列；**库存水位条**（刻度线=预警阈值，低库存为黄黑斜纹，行首黄色标记，状态徽标“低库存”）；行操作；空状态带“清除筛选条件” |
| 商品详情 | `products/detail.html` | 大号库存数字 + 全宽水位条；一致性核对结果卡片；流水表 |
| 商品/分类/供应商/用户表单 | `*/form.html` | label 与输入框 `for` 关联；返回按钮图标化；启用账号复选框改为大点击区域 |
| 分类、供应商、用户列表 | `categories/list.html` 等 | 统一表格样式、行操作、徽标、空状态 |
| 入库 / 出库表单 | `stock/in-form.html`、`stock/out-form.html` | 左右布局：单据表单 + **库存预览面板**（实时计算操作后库存，出库超量时红色提示“提交后服务端会拒绝”）；幂等号以虚线标签展示；仅提示，不拦截提交，最终以服务端为准 |
| 入库 / 出库列表、库存流水 | `stock/*-list.html`、`stock/flows.html` | 数量用绿色 +n / 橙色 −n；“库存变化”用箭头；商品可点击进入详情 |
| 一致性核对 | `stock/consistency.html` | 结果横幅带图标；商品名+编码合并 |
| 403 / 错误页 | `error/403.html`、`error.html`、`error/error.html` | 图标 + 说明 + “返回上一页 / 返回首页” |
| 分页 | `fragments/pager.html` | 上一页/下一页 `aria-label`、当前页 `aria-current` |
| 样式 | `static/css/app.css` | 完整重写：令牌、布局、按钮、徽标、表格、水位条、图表、表单、Toast、弹窗、响应式、reduced-motion |
| 脚本 | `static/js/app.js` | 重写：提交防抖（加载圈）、确认弹窗、分页保参、水位条、库存预览、Toast、抽屉导航+面包屑、SVG 柱状图、环形图、千分位 |

**未改动**：所有 Controller / Service / Repository / Entity / SecurityConfig、所有 URL、表单字段名（含 `requestId` 幂等号隐藏域）、权限规则。原有 `scripts/check-pages.sh`、`scripts/smoke-ui.sh` 无需修改即全部通过，说明页面契约保持不变。

## 5. 已知限制

- 中文字体使用系统字体，不同操作系统下字形略有差异（Windows 为微软雅黑、macOS 为苹方）；未打包中文字体是为了避免十几 MB 的体积。
- 柱状图在压测当天的数据量（20 万级）远大于日常，线性刻度下其它日期的柱子很矮，因此提供了“对数”切换。2026-11-16 已把运行库换成干净演示数据（`docs/12-演示数据说明.md`），现在线性刻度下就能看清，对数切换仍然保留。
- ~~演示数据中保留了压测/冒烟测试生成的商品~~ → 已于 2026-11-16 清理（清理前已备份），`docs/screenshots/redesign/after/` 中受数据影响的截图已用新数据重拍；`before/` 与 `compare/` 仍是重构当时（含压测数据）的截图。重拍后的交互验收 12/12 通过：`docs/test-results/ui-interaction-demo-data.txt`。
- 交互验收脚本会真实提交一张入库单（向“秒杀演示商品 P9001”入库 5 件）；验收后已通过出库接口扣回 5 件，库存恢复为 50，一致性核对仍为一致（两条流水保留在库存流水中）。
